TNSAIML_Training




Retail Sales Forecasting Using Machine Learning
Project Description
This project analyzes historical retail sales data and predicts future monthly sales using the Linear Regression algorithm.

Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly
- Joblib
  
Features
- Amazon e-commerce dataset analysis
- Monthly and category-wise sales analysis
- Linear Regression model training
- Model evaluation using MAE, MSE, RMSE, and R² Score
- Future monthly sales prediction
- Graphical visualization of actual and predicted sales
